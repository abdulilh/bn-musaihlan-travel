# بن مسيحلان للسفريات والسياحة

هذه نسخة عامة ثابتة من الموقع التعريفي لشركة **بن مسيحلان للسفريات والسياحة وخدمات الحج والعمرة**، مهيأة للنشر عبر GitHub Pages.

تتضمن النسخة صفحات عربية RTL، صور العروض الرسمية، بيانات SEO، ملفات `robots.txt` و`sitemap.xml`، وروابط تواصل مباشرة عبر واتساب. تُحوِّل نسخة GitHub Pages نموذج الاستفسار إلى رسالة واتساب، لأنها لا تشغّل خادمًا أو قاعدة بيانات.
